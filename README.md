Compact Claustrophobia could be reimplemented from scratch in canvas without taking on all of the cruft coming from minecraft.
It doesn't have to support procgen or arbitrarily many voxels.
It doesn't have to port over every useless feature coming from random mods and the base game.

The way would be to scrape guides for the mod and wikis and starting with the features that are at the beginning of the modpack.

It would be more of a factory game if it wasn't strangled by having to conform to the base game.
